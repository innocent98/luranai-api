Getting Started Walkthrough (Tenant Admin)

Quick setup checklist
1. Create your account and verify email.
2. Upload your first knowledge files.
3. Configure your widget look and greeting.
4. Create a public API key.
5. Install the widget snippet on your website.
6. Run a real test conversation.

Step 1: Account and Trial
- After signup, your workspace and tenant admin account are created automatically.
- Trial starts immediately and currently lasts 30 days.
- Verify your email, then sign in to dashboard.

Step 2: Upload Knowledge
- Upload files your customers ask about most.
- Supported: `.txt`, `.md`, `.pdf`, `.docx`.
- Max file size: `10 MB` per file.
- Uploads process in the background. Status moves from `PROCESSING` to `ACTIVE` when ready.
- Start with FAQs, pricing, support policies, onboarding guides, and troubleshooting steps.

Step 3: Build Flows (Optional, Recommended)
- Flows help guide users with step-by-step options.
- Good examples: Data / Airtime / Services menu, billing troubleshooting, escalation to human support.
- Use clear flow names because customers may see these as menu options.
- If a request is not handled by flow, chat can continue with AI/RAG.

Step 4: Configure Widget
- In Widget settings, set brand colors, welcome greeting, position, company logo, unread badge, and file-upload options.

Step 5: Install Widget Snippet
Add before `</body>`:

```html
<script>
  window.luranSettings = {
    tenantId: 'YOUR_TENANT_UUID',
    apiKey: 'YOUR_PUBLIC_API_KEY'
  };
</script>
<script src="https://cdn.luranai.com/widget/v1/widget.js" async defer></script>
```

- Use public key only (`pk_live_...`), never a secret key.

Step 6: Verify End-to-End
- Open your website and launch widget.
- Confirm greeting appears.
- Ask a question covered by knowledge base.
- Test a flow path (if you created flows).
- Test escalation to human support.
- Confirm agent reply from dashboard appears in widget.

Common issues
- Wrong `tenantId` or API key in script.
- Knowledge source still `PROCESSING` or in `FAILED` state.
- Plan limits reached (knowledge, flows, storage, conversations).
- Subscription inactive.
