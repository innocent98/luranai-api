================================================================================
OVERVIEW
================================================================================

Luran currently uses 5 tiers:
- trial
- lite
- professional
- growth
- enterprise

Currency in seed data is kobo (NGN x 100).

Important implementation notes:
- Self-service signup creates a trial tenant with trial_ends_at = now + 30 days.
- Platform-admin override to trial currently sets +14 days when trial is reset.
- Capability enforcement is done at runtime using tenant capabilities.

================================================================================
ENFORCEMENT BEHAVIOR
================================================================================

- Flow create limits are enforced in flow_service.check_flow_limits().
- Node-per-flow and webhook permissions are validated before save/execute.
- Knowledge source count and storage are enforced at upload/scrape time.
- Conversation limits are checked monthly in verify_conversation_limit().
- Inactive subscription states (trial_expired, canceled, past_due) are blocked
  by verify_subscription_active() on protected routes.

================================================================================
CANCELLATION / EXPIRY
================================================================================

- Trial expiry: tenant moves to trial_expired and protected features are blocked.
- Active subscription past subscription_ends_at: marked canceled and blocked.
- Immediate cancel: status set to canceled now.
- End-of-period cancel: remains active until subscription_ends_at.

This file is intentionally implementation-first. If plan policy changes, update both
seed data and this doc together.
