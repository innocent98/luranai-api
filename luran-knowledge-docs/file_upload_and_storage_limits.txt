File Upload and Storage Limits

How file upload works (for tenant admins)
- Go to your Knowledge section and upload a file.
- Supported file types: `.txt`, `.md`, `.pdf`, `.docx`.
- Max file size: `10 MB` per file.
- Empty files are rejected.
- Files with no meaningful text (less than 10 extracted characters) are rejected.

What happens after you upload
- Luran accepts the upload and queues it for background processing.
- Your source status starts as `PROCESSING`.
- Luran extracts text, splits it into chunks, and creates embeddings.
- Once processing succeeds, status becomes `ACTIVE`.
- If processing fails, status becomes `FAILED`.

When your AI agent starts using the file
- Your agent uses knowledge from processed chunks in your knowledge base.
- In practice, treat `ACTIVE` as the ready state for full use.
- If a source is `PROCESSING`, results can be incomplete until processing finishes.

Storage and source limits
- Limits are enforced by your subscription capabilities.
- Two limits are checked: total storage (MB) and total number of knowledge sources.

Default storage limits by tier
- trial: `10 MB`
- lite: `50 MB`
- professional: `200 MB`
- growth: `500 MB`
- enterprise: unlimited

Default source-count examples
- trial: `2` sources
- higher tiers: larger limits based on plan
- URL/webpage sources are plan-gated (for example, trial can be file-only).

What counts toward storage
- File uploads and URL knowledge sources
- Sources in `ACTIVE` and `PROCESSING` states

What does not count toward this storage metric
- Conversations
- Widget settings
- Team members

If you hit a limit
- Upload is blocked.
- You receive a clear error with current usage and plan limit.
- Upgrade your plan or remove old/inactive knowledge sources.

If you delete a source
- The source is set to `INACTIVE`.
- Its chunks are deactivated and vectors are removed.
- This helps reduce active knowledge footprint and usage.
