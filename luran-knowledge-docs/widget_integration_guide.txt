Luran Widget Integration Guide (Tenant Version)

What you need before install
- Your `tenantId` (from dashboard).
- Your public API key (starts with `pk_live_`).

Important:
- Use public key only in website code.
- Never expose secret keys (`sk_live_`) in frontend.

Quick install
Add this before `</body>` on your website:

```html
<script>
  window.luranSettings = {
    tenantId: 'YOUR_TENANT_UUID',
    apiKey: 'YOUR_PUBLIC_API_KEY'
  };
</script>
<script src="https://cdn.luranai.com/widget/v1/widget.js" async defer></script>
```

What happens after install
1. Widget reads your `tenantId` and public key.
2. It loads your widget settings (name, colors, greeting, logo, position).
3. It shows the floating chat button on your website.
4. When users open it, chat starts with your tenant configuration.

What you can customize in dashboard
- brand colors
- company name/description
- greeting message
- widget position
- logo
- unread badge
- file upload toggle

If you upload a logo:
- Max logo upload size is `5 MB`.

How to test quickly
1. Publish the snippet on a page.
2. Open page in browser.
3. Confirm floating button appears.
4. Open chat and send a test message.
5. Confirm message appears in your dashboard support view.

Common issues and fixes
- Widget not showing:
  - missing or wrong `tenantId`
  - missing or wrong public API key
  - script not loaded (check browser console/network)

- Config request fails:
  - `401`: API key is invalid/revoked
  - `403`: API key does not belong to that tenant
  - `404`: tenant ID is wrong

- Chat opens but answers are weak:
  - knowledge files may still be `PROCESSING`
  - no `ACTIVE` knowledge sources yet
